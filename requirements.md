# Project Requirements

## Project Title
Multilingual AI-Based Job & Skill Recommendation System for Indian Students

## Problem
Indian students often struggle to identify suitable jobs based on their skills due to lack of guidance, language barriers, and fragmented information.

## Solution
An AI-powered system that accepts user skills in Hindi or English and recommends relevant job roles, identifies skill gaps, and suggests personalized learning paths.

## Key Features
- Multilingual input support (Hindi/English)
- Job role recommendations
- Skill gap analysis
- Learning roadmap suggestions
- Dashboard for insights

## Target Users
- Students
- Fresh graduates
- Job seekers in India
